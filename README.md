# 🥤 DrinkProductionSite — REST API Завода Напитков

Backend-сервис для управления каталогом напитков и категорий с разграничением прав доступа (RBAC) и JWT-авторизацией.

## 🚀 Технологический стек
- **Python 3.10+**
- **FastAPI** (асинхронный веб-фреймворк)
- **SQLAlchemy** (ORM для работы с базой данных)
- **SQLite / Alembic** (БД и миграции)
- **Pydantic** (валидация данных и схем)
- **PyJWT / OAuth2PasswordBearer** (аутентификация и авторизация)

## 📌 Функционал и особенности
- **Публичные эндпоинты (`GET`):** Просмотр списка товаров и категорий доступен всем пользователям.
- **Админ-панель (`POST`, `PUT`, `PATCH`, `DELETE`):** Создание, редактирование и удаление товаров/категорий защищено проверкой прав администратора (`is_admin=True`).
- **Swagger UI:** Автоматическая документация API и встроенная авторизация через кнопку `Authorize`.
- **Валидация:** Проверка уникальности названий категорий и корректности данных.
